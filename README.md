# BCG Customer Churn Prediction

A machine learning project for predicting customer churn using customer and pricing data.

## Features

- Customer churn prediction using a trained Random Forest model
- Streamlit frontend for uploading data and viewing predictions
- FastAPI backend for serving prediction requests
- Prediction results with churn probabilities
- Feature-based analysis using the prepared dataset

## Tech Stack

- Python
- Pandas and NumPy
- Scikit-learn
- FastAPI
- Streamlit
- Joblib
